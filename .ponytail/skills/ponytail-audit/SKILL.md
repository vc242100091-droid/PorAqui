  Auditoría completa del repositorio: busca errores, riesgos de seguridad, código muerto, funciones duplicadas y oportunidades para simplificar o eliminar código.
---

Audita el repositorio con visión de desarrollador senior para identificar deuda técnica y código sobrante.

## Puntos de análisis:
1. Mapea puntos de entrada, flujos principales y dependencias.
2. Busca errores, fallos de seguridad, cuellos de botella y pruebas faltantes.
3. Identifica código para eliminar, reusar, reemplazar por funciones estándar o refactorizar (YAGNI).
4. Genera un reporte detallado ordenado por impacto.
